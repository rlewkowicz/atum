# Maintained Platform Overrides

This ledger documents the values Atum still authors. It is not a second values
source. Big Bang, its selected package charts, and the selected official
application charts remain authoritative.

The evidence baseline is Big Bang `3.31.1`
(`b9a49842b930b4e5706265d26867ee7f0ba79d5b`), generic-package wrapper
`0.4.15` (`86b9ecc74169cb4f9635e7a5ed695014390e9efc`), OpenSearch and
OpenSearch Dashboards chart/application `3.8.0`, Fluent Bit `0.57.9-bb.0`,
GitLab `10.2.4-bb.0`, Grafana `10.5.15-bb.6`, Harbor `1.19.2-bb.0`,
Headlamp `0.44.0-bb.0`, Istio Gateway `1.30.3-bb.0`, Keycloak
`7.3.0-bb.0`, Kiali `2.30.0-bb.0`, Kyverno `3.8.2-bb.2`, Kyverno Policies
`3.3.4-bb.87`, Kyverno Reporter `3.9.0-bb.1`, Monitoring `88.3.0-bb.0`,
Authservice `1.1.5-bb.7`, Tempo `2.1.0-bb.2`, Vault `0.34.0-bb.0`,
Kubernetes `1.35.4`, and Kubespray `v2.31.0`.

Evidence paths are relative to those exact selected sources. Big Bang inputs
come from `chart/values.yaml` and the named `chart/templates/*/values.yaml`;
maintained-package inputs come from their `chart/values.yaml` and named
templates; official application inputs come from the packaged
`opensearch/values.yaml`, `opensearch/templates/statefulset.yaml`,
`opensearch-dashboards/values.yaml`, and
`opensearch-dashboards/templates/deployment.yaml`; Fluent Bit Pod extensions
come from `chart/charts/fluent-bit/values.yaml` and
`chart/charts/fluent-bit/templates/_pod.tpl`. The exact selected commits and
chart archives are recorded in `atum.lock.json`; this ledger does not treat
tests or cache paths as deployment APIs.
